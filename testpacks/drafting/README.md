# 尺规绘图验收研究

这是 Minecraft 1.20.1 的可选测试数据包。研究与成果位于 `data/twr_researches/frostedresearch/knowledge/`。项目的阶段任务引用 FrostedHeart 提供的 `frostedresearch:drafting/four_blade_pump` 图纸。

将整个 `drafting` 目录放入测试世界的 `datapacks/`，重载后用 `/knowledge grant idea twr_researches:drafting_test` 取得测试想法。在绘图台的研究页启动「尺规绘图试验」，进入阶段任务「绘制四叶螺旋桨泵」。完成后可结题取得「四叶泵试绘记录」。
