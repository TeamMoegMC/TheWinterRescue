# 地形与群系

本目录描述 TWR `1.20` 的正常主世界、地下群系和区域矿床。当前分支 JSON、生成脚本及 FH 实现为权威，不以文件名称或旧截图推断机制。

| 文档 | 内容 |
|---|---|
| [生成总览](overview.md) | 正式入口、密度路由、两仓库职责与验证流程 |
| [群系与洞穴](biomes-and-caves.md) | 群系分布、挖掘形状、wide_cave 与冰洞装饰 |
| [建筑结构与遗迹](structures.md) | 自定义结构集、群系资格、模板池、村庄覆盖与调参 |
| [热液矿床](hydrothermal-deposits.md) | 区域概率、位置、大洞厅、材料与资源导出 |

先从总览确认生效链，再查具体配置。调参数后分别验证分布、几何、装饰、产量和生成耗时，不能只靠 JSON 能解析便宣布玩法验证通过。
